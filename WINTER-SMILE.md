# All-Inclusive Smile — winter 2026

The dental campaign now has a patient landing page and an expandable advisor desk at the existing `/{en,tr,ru,es,it}/kampanya/dental/` paths under `/campaignscard/`. `?view=advisor#advisor` opens the advisor desk directly. Copied patient links omit the advisor query and anchor.

The owner approved the €3,000 price, flight inclusion and validity through 31 December 2026 on 2 November 2026. The original campaign supplies 20 crowns, 7 hotel nights, one companion's accommodation, airport/clinic transfers, a €300 patient return-flight allowance and a minimum €300 deposit. Treatment dates are agreed individually; no new treatment-completion deadline is inferred from campaign expiry. Implants, flight excess, visas and insurance remain separate. Material and warranty details are qualified by written terms.

`src/data/winter-smile.ts` stores the commercial constants and EN/TR copy; `winter-locales.ts` adds RU/ES/IT. Listing cards derive their data from these same translations. Other campaigns retain their existing renderer and content.

Media was imported from landing source release `20261029T161132Z-cc833b9f5cd9-6a4453b0`. `public/winter-smile/provenance.json` records the original public paths and byte hashes. All 10 clinical examples are unchanged. The four illustrative guide images show front smile, right bite, lower arch and upper arch. Hotel images show the usual Pullman option, subject to booking confirmation and the original minimum 4-star category.

The two campaign designs per language combine the existing illustrative Bosphorus portrait or real treatment-room photograph with the updated package terms. SVG masters and JPEG exports are generated by `npm run prepare:winter-art`. Rasterization uses Sharp and resvg; it does not alter the clinical example photographs. Videos use the current public landing media endpoints and load only after a click; their original audio is labelled.

The page does not collect or submit patient data. Advisor buttons copy text. Image sharing uses the native file-sharing API when supported, with ZIP download and patient-link alternatives. No WhatsApp message is sent automatically. ZIP selection spans categories; selecting visible media adds only the current category.

Validation: `npm run check`, `npm run build`, `npm test`. Browser QA covers 320/390/768/1024/1440 px in all five languages, selection across categories, a downloaded ZIP matched to source bytes, and real video playback/close behavior. Deployment remains the existing Coolify application 22 / `ime-campaignscard`; no main-site or shared landing publication is needed.
